# spoonjoy/.github

The Spoonjoy organization's profile and brand files for GitHub.

- `profile/README.md` is the page at [github.com/spoonjoy](https://github.com/spoonjoy).
- `brand/headers/` holds each README's header, light and dark. `brand/social/` holds each repository's social preview (1280x640).
- `brand/surfaces.json` lists every surface that carries them, and `brand/provenance.json` says where each image came from.
- `brand/tools/audit.mjs` checks every surface; the `brand audit` workflow runs it daily and on every change.

To change the brand, read [AGENTS.md](AGENTS.md) first.
